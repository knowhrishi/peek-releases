# Peek releases

Signed and notarized builds of [Peek](https://peekhq.app), the Mac app that turns screenshots into
descriptions any AI can read.

This repository holds downloads only. The app's source code is private.

## Download

- **Latest:** <https://peekhq.app/download>, or the newest entry under
  [Releases](https://github.com/knowhrishi/peek-releases/releases).
- Each release has the versioned file (`Peek-<version>.dmg`) and the same build as `Peek.dmg`, so
  `https://github.com/knowhrishi/peek-releases/releases/latest/download/Peek.dmg` always points at the newest one.

Needs a Mac with Apple silicon on macOS 15 Sequoia or later.
